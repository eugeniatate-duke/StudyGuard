# StudyGuard project plan

## Purpose
Encourage independent effort and thoughtful use of AI assistance
through an inline interface on supported AI chat websites.

## Course connection
Human–AI Interaction, AI Harms, and AI Evaluation.
The project develops the redesign proposed in my earlier case study
on overreliance on AI in education.

## Main interface
StudyGuard appears beside the chat input on a supported website.
The extension popup contains settings.

## Planned workflow
1. Invite the user to record an attempt or explain where they are stuck.
2. Offer a hint or feedback on their reasoning.
3. Prepare a revised prompt for the user to review before sending.
4. Offer an optional reflection after assistance.

Users can skip the intervention or turn study mode off.

## Initial scope
- One supported AI chat website.
- Local settings.
- User-approved prompt changes.
- No separate model, backend, or API required.
- No automatic submission of prompts.

## Boundaries
StudyGuard does not detect cheating or prove independent work.
It does not guarantee that an AI model follows hint instructions.
Improved learning and reduced dependence remain untested hypotheses.
Native desktop and mobile apps are outside the initial scope.

## Current status
Extension manifest and settings popup placeholder created.
Inline functionality and settings behavior are not implemented.
