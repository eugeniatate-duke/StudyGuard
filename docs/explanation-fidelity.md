# Explanation quality: agreement, faithfulness, stability

Generated by `node eval/explanation_eval.js`. No human labels are used; this measures how the
explanations relate to the model and rules themselves.

Prompts analysed: 124 (dev + held-out, at least 3 words). Model holds 75; rules hold 57; both hold 52.

## 1. Agreement between methods

Spearman = median rank correlation of per-word values within a prompt (1 = same ranking).
Top-1 = how often both methods pick the same most HOLD-ward word. Top-3 = average overlap of top-3 sets.

| Method A | Method B | Prompts | Median Spearman | Top-1 agree | Top-3 overlap |
|---|---|---|---|---|---|
| model-shap | model-lime | 74 | 0.93 | 92% | 85% |
| model-shap | model-occl | 74 | 0.91 | 88% | 84% |
| model-lime | model-occl | 74 | 0.93 | 86% | 85% |
| rules-perturb | model-shap | 49 | 0.39 | 38% | 46% |
| rules-perturb | model-occl | 49 | 0.37 | 36% | 46% |
| rules-perturb | model-lime | 49 | 0.37 | 40% | 46% |

## 2. Faithfulness: deletion test

For prompts the model holds (n=73), delete the k words a method ranks most HOLD-ward and re-run the model.
Larger p(HOLD) drop and higher flip rate = more faithful. Random = k random words (30 draws).
Note: occlusion's top-1 is the best single deletion by construction, so it is an upper bound at k=1.

## 3. Stability

LIME run twice with different random seeds on 75 model-held prompts: median Spearman 0.96, same top-1 word 92%.
SHAP (exact for a linear model), occlusion and rule perturbation are deterministic: identical results on every run.

## Limitations

- These checks show consistency with the model, not that students understand or benefit; no user study was run.
- Prompts are the dev and held-out prompts (drafted mostly by an AI assistant, not from real students); short prompts have few words, so rankings are coarse.
- Deleting words can create ungrammatical text the model never saw; deletion-test numbers are indicative.
- SHAP here uses the training prompts as background; a different background changes values (not the ranking much).
- Prompts where rules and model tokens could not be aligned (e.g. accented letters) are skipped in rule-vs-model comparisons.
