StudyGuard v1.1.0: a glass-box prompt coach for ChatGPT and Claude.

**Install (no build needed):** download `studyguard-v1.1.0.zip` below, unzip it, open `chrome://extensions`, switch on Developer mode, click Load unpacked, and choose the unzipped folder. Requires Chrome 116 or newer.

**What's new since 1.0.0**
- A slim, collapsible bar that opens when a prompt is held and folds away after you send
- Hold card with three choices: add your own thinking, get a hint instead, or send anyway
- Hint builder: asks the AI for one hint at a time and types the request into the chat box; StudyGuard never holds its own hint requests
- Redesigned popup and a logo
- README refresh with two demo GIFs, citation file, and a one-command build of the extension zip (`python scripts/package.py`)

**What it is and is not.** A rule-based scorer with a transparent explanation, plus a trained model for comparison. It looks at visible effort in a prompt; it does not understand the problem, and its hints are templated. It is a coaching tool, not an academic-integrity detector. See `docs/limitations-and-ethics.md`.

149 automated tests pass. Everything runs on the student's device; no account, no network calls.
